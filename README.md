# Alternate Oak Intro

A faster, more natural start to a Kanto adventure.

**Alternate Oak Intro** moves your starter choice into Professor Oak's opening introduction and restructures the beginning of the game around it. Instead of repeating the familiar trip to Oak's Lab before your journey can begin, you leave home already partnered with your first Pokémon.

The mod supports both the Generation I and FireRed/LeafGreen versions of G1R Deluxe, with the opening adapted to fit each game.

## Features

- Choose Bulbasaur, Charmander, or Squirtle during Oak's introduction
- Nickname your starter before entering the world
- Reworked early-game progression that gets the journey moving immediately
- Rival encounter adapted around the new opening
- Early key items and tutorial progression adjusted to fit the alternate start
- Optional integration with Choose Your Avatar and Kanto Gear

## Installation

Install **Alternate Oak Intro** through G1R Deluxe's mod browser, or import the mod ZIP manually.

No additional mods are required.
